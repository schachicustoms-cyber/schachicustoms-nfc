TIMING · 01

Chains

When several effects are triggered together, GOAT Format uses the familiar simultaneous-effects procedure — with one important ordering detail.

The core idea

A Chain is built before it resolves. Once every player has added the effects they can activate, resolve the Chain backwards: the highest Chain Link resolves first.

If multiple Trigger Effects happen at the same time, place them on the Chain in this order:

  1. The turn player’s mandatory effects.
  2. The opponent’s mandatory effects.
  3. The turn player’s optional effects that did not miss timing.
  4. The opponent’s optional effects that did not miss timing.

The GOAT Format detail

If effects were triggered at different moments, an earlier Trigger Effect must be placed on the Chain before one that was triggered later. Work through the four steps above for each moment in which effects triggered.

EXAMPLE

Sangan is Tributed to Tribute Summon Thestalos the Firestorm Monarch. Sangan’s mandatory effect triggered first, so it is Chain Link 1. Thestalos’s mandatory effect is Chain Link 2. Thestalos resolves first; Sangan then resolves.

Quick check

  • Build the entire Chain before resolving any of its links.
  • Resolve from the last Chain Link to the first.
  • For Trigger Effects, identify both the player and the exact time each effect triggered.
AT A GLANCE Earlier triggers go on the Chain before later triggers.

That ordering is the key GOAT Format difference for simultaneous effects.
